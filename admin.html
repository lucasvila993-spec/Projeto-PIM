    Dados

    Os dados ficam salvos somente neste navegador. Use os arquivos .txt para trocar dados com o programa em C.

    Exportar

    Baixa pacientes.txt, agenda.txt e fila.txt no mesmo formato do nylt_agenda.c, e presenca.txt com confirmações e faltas.

    Importar

    Selecione um ou mais arquivos (pacientes.txt, agenda.txt, fila.txt, presenca.txt). Os dados atuais de cada arquivo escolhido serão substituídos.
